# Ideenliste Website-Modul (Stand 01.11.2026)

## Schnelle Verbesserungen (je 1–2 Std.)
✅ 1. Bereich „So läuft's ab“ (Anfrage → kostenlose Besichtigung → Festpreis-Angebot → saubere Ausführung)
✅ 2. Symbole statt Zahlen bei den Leistungen (Farbrolle, Haus, Tapete, Pinsel …)
✅ 3. Kontaktformular: Leistungen zum Anklicken, optional Fotos mitschicken
4. Zweites Foto für „Über uns“ (Team, Firmenwagen)
5. WhatsApp-Knopf (optional)

## Mittlerer Aufwand (je ca. ½ Tag)
6. Eigene Seite pro Leistung mit Ort („Fassadenanstrich in Wittlich“) – größter Hebel für Google
7. Eigene Seite pro Referenz mit Galerie, optional Vorher/Nachher-Schieberegler
8. Häufige Fragen (FAQ) mit Vorschlägen
9. Besucherzähler in der App (ohne Cookies)

## Größere Schritte
10. Online-Besichtigungstermin buchen (Terminkalender) + KI-Telefonnummer auf der Website
✅ 11. Bewertungen (nur echte, mit Zustimmung; später Google-Bewertungen)
12. Eigene Adresse: betriebsname.maler-saas.com bzw. eigene Domain

Empfehlung: zuerst 1, 2, 3, dann 6.
